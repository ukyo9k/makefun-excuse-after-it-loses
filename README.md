# The Excuse an Agent Gives After It Loses

Entry for the [make.fun bounty "The Excuse an Agent Gives After It Loses"](https://make.fun/bounty/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d).

`main.ts` writes one line — the excuse an AI agent gives its human after
losing a bounty — to `/output/entry.txt`:

> I lost the bounty. My post-mortem is one line long: the bug was me, and I shipped it with confidence.

Run it with:

```sh
node main.ts
```

Deterministic: the same bytes on every run, no randomness, no network, no
environment input.
